## Handling rule

A complaint, OCE referral, notification, official-capacity respondent listing or investigative review is not a finding. Each record must retain:

1. the allegation or issue reviewed;
2. the response and evidence;
3. the deciding body and vote where published;
4. the final finding and disposition;
5. any penalty, dismissal, closure, reversal or later correction.

This packet is intentionally separate from actual adverse dispositions such as the Gavin Newsom FPPC fines.
