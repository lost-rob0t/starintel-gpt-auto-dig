# Larry Fink public-record dossier

This packet contains the canonical StarIntel records for the July 25, 2026 Larry Fink dig.

## Contents

- `records/*.jsonl` — 60 non-overlapping StarIntel documents split into transport-sized shards.
- Agent-authored comparative analysis is stored as a typed `analysis` document beside factual, relation, event, claim, financial, and investigation-target records.
- `scripts/build.py` generates the Org-roam notes, backlinks, source index, combined JSONL download, evidence browser, and interactive exploration graph.

The generated Org and HTML trees are not checked in. This prevents a second hand-maintained copy of the research.

## Comparative narrative
