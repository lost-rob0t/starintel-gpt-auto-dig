# Larry Fink comprehensive public-record dig

This packet contains the canonical StarIntel JSONL dataset for the Larry Fink research site.

The committed source of truth is `starintel-documents.jsonl.gz.b64`, a gzip-compressed, base64-encoded JSONL stream. The build publishes a decoded `starintel-documents.jsonl` download. Org-roam nodes, graph data, readable source indexes, and HTML pages are generated by `scripts/build_research_site.py`; they are not duplicated in version control.

The analysis separates verified facts, pending allegations, estimates, open investigation targets, and a neutral structural comparison with corporatism and fascism.

## Build

```bash
python3 scripts/build_research_site.py \
  --input digs \
  --output _site \
  --org-output .generated/org
```
