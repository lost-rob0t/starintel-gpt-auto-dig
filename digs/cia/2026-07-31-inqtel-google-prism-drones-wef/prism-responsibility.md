# PRISM / FISA Section 702 responsibility matrix

This branch is intentionally separate from the Keyhole–Google–Niantic lineage.

| Entity | Publicly documented role in this packet | Evidence boundary |
|---|---|---|
| NSA | Receives all PRISM collection under the PCLOB description; targeting and acquisition role | This does not make every Google service or dataset a PRISM source |
| FBI | Receives a selected portion of PRISM collection and has downstream querying/operational roles described in oversight material | Receipt and querying must be tied to exact legal and compliance records |
| CIA | Receives a selected portion of PRISM collection under the PCLOB description | PRISM is not represented as a CIA-run program |
| Google | Named in leaked PRISM presentation material; publicly denied direct server access or a back door and said disclosures followed law | Provider naming, compelled production, and direct access are separate claims |
| PCLOB | Oversight body whose report describes program mechanics and agency roles | Its findings are the primary public mechanics source used here |
| Niantic / Pokémon GO | No direct public evidence found in this pass of PRISM collection involving their data | Absence in this bounded source pass is not proof of categorical absence |

## Core rule

Do not merge the PRISM branch with the CIA → IQT → Keyhole → Google → Niantic → Pokémon GO corporate and technology lineage. Shared nodes do not establish shared data flows.
