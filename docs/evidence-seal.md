# StarIntel Evidence Seal

Auto-Dig publishes a cryptographic receipt for the exact complete-corpus JSONL generated by the research site.

The receipt combines two checks:

- `corpus_file_sha256` commits to the exact downloaded bytes;
- `merkle_root_sha256` commits to every canonical record, its line, and its published location through a domain-separated binary Merkle tree.

A changed value, removed record, added record, reordered line, or altered corpus file fails verification. JSON key order and insignificant JSON whitespace normalize to the same canonical record hash, while the whole-file SHA-256 still detects the byte-level difference.

## Create and verify a seal

```bash
python3 scripts/evidence-seal.py create \
  _site/downloads/starintel-complete-corpus.jsonl \
  --output _site/downloads/starintel-evidence-seal.json

python3 scripts/evidence-seal.py verify \
  _site/downloads/starintel-complete-corpus.jsonl \
  _site/downloads/starintel-evidence-seal.json
```

## Generate and verify a record proof

```bash
python3 scripts/evidence-seal.py prove \
  _site/downloads/starintel-complete-corpus.jsonl \
  starintel:claim:example \
  --receipt _site/downloads/starintel-evidence-seal.json \
  --output example-proof.json

python3 scripts/evidence-seal.py verify-proof \
  example-proof.json \
  --receipt _site/downloads/starintel-evidence-seal.json
```

The proof contains the canonical document, leaf metadata, and the minimum sibling hashes required to reconstruct the published root. It can be verified without loading the rest of the corpus.

## Tree construction

1. Canonicalize each record with UTF-8 JSON, sorted keys, and compact separators.
2. Hash the canonical record with SHA-256.
3. Build a leaf entry containing `_id`, dataset, dtype, document hash, line, path, and surface.
4. Hash `STARINTEL-EVIDENCE-LEAF-V1\0 || canonical_leaf_entry`.
5. Pair leaves in deterministic publication order.
6. Hash each internal node as `STARINTEL-EVIDENCE-NODE-V1\0 || left || right`.
7. Duplicate the final node when a level has odd width.

The domains prevent a leaf from being interpreted as an internal node.

## Evidence boundary

The seal proves publication and integrity. It does **not** prove that a claim is true, a source is reliable, an identity match is correct, an investigation is complete, or an inference is justified. Those remain evidence-review questions.
