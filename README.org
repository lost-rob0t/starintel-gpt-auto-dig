* Canonical schema

The =starintel_doc/= Python package is the repository's only document specification. The JSON Schema under =schemas/= is generated from that package. Skills, scripts, renderers, and research packets must not define parallel document shapes.

* Canonical data

- =db/<dtype>/<_id>.ndjson= stores one normalized document per file.
- =digs/<target>/<run>/starintel-documents.jsonl= stores packet-oriented research.
- Common metadata lives in the v0.9.0 envelope.
- Dtype-specific metadata lives in the strict =data= object.
- Unrepresentable legacy values are preserved under namespaced =extensions=.
